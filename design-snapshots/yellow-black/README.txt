# استرجاع لوحة الأصفر/الأسود

هذه نسخة محفوظة قبل تحويل الألوان إلى لوحة sage الجديدة.

## الألوان القديمة
- Accent: #F8E008
- Dark: #000 / #111
- Paper: #E6DFD0

## الألوان الجديدة (الحالية في المشروع)
- Ink / bg: #1E201E
- Surface: #3C3D37
- Sage: #697565
- Paper: #ECDFCC

## طريقة الرجوع
انسخ الملفات من هذا المجلد إلى أماكنها:

- globals.css, page.tsx, layout.tsx → src/app/
- Footer.tsx → src/components/
- home/*.tsx → src/components/home/
- images/* → public/images/

أو اطلب من المساعد: "ارجع للألوان القديمة من design-snapshots"
