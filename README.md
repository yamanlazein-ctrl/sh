# منصة الشيخ الصابوني — الأرشيف العلمي

إعادة تصميم كاملة بهوية **«ليلة الزمرد وذهب المخطوطات»** (Emerald Night & Manuscript Gold).

## الهوية البصرية الجديدة

| الرمز | اللون | الاستخدام |
|---|---|---|
| `ink` `#04100C` | أسود مخضرّ عميق | خلفية الموقع كلها |
| `ink2/ink3` | زمردي داكن | البطاقات والأسطح المرفوعة |
| `gold` `#D4AF6A` | ذهب المخطوطات | اللون الرئيسي: الأزرار، الروابط، التمييز |
| `gold2` `#EACD93` | ذهب فاتح | التحويم والعناوين الفرعية |
| `ivory` `#F5F0E3` | عاجي | النصوص بدل الأبيض النيء |
| `emd` `#145443` | زمردي | الأسطح الممتلئة (بانر المتجر…) |

الألوان معرّفة كـ tokens في `src/app/globals.css` عبر `@theme` (Tailwind v4)، فتُستخدم مباشرة:
`bg-gold` · `text-gold2` · `border-gold/30` · `bg-emd` … إلخ.

خطوط: Cairo Black للعناوين (`.font-display`)، IBM Plex/Readex للنصوص،
وأُضيف **Amiri** (`.font-quran`) للاقتباسات والنصوص القرآنية.

## فيديو الخلفية السينمائية للواجهة (الأهم)

مكوّن `src/components/home/HeroCinema.tsx`:

1. **إذا وضعت فيديو حقيقياً للشيخ** (تلاوة فجرية، فتوى قصيرة، لمحة تعريفية) في:

   ```
   public/videos/sheikh-intro.mp4
   ```

   يُشغَّل تلقائياً كخلفية صامتة متكررة، مع زر لتشغيل الصوت، وشارة «فيديو الشيخ يُعرض الآن».
   (يُفضَّل: MP4 / H.264 / دقة 1280–1920 / حجم أقل من 15MB / 20–60 ثانية).

2. **إذا لم يوجد الفيديو**، تعمل بدلاً منه مشاهد سينمائية مولّدة بحركة Ken Burns
   وتقاطع ناعم مع تعليقات نصية متغيّرة — فلا تظهر الواجهة مكسورة أبداً.

لتغيير نصوص التعليقات أو الصور: عدّل مصفوفة `SCENES` داخل المكوّن.

## لمحة فيديو في قسم «من هو الشيخ»

أسفل بورتريه الشيخ بطاقة «لمحة فيديو · تلاوة وفتوى» تنقل الزائر إلى قسم المرئيات.

## التشغيل

```bash
npm install
npm run dev     # التطوير
npm run build   # الإنتاج
```

## أصول الصور

الصور في `public/images/` مولّدة بالهوية الجديدة (زمردي/ذهبي) وهي محتوى تجريبي
يُستبدل بالصور الأرشيفية الحقيقية للشيخ لاحقاً بنفس الأسماء.
